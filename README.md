# baby-brand

Storefront mockups for the baby products e-commerce brand.

## Pages

- `pages/bottle-warmer-pdp.html` — Portable bottle warmer product page (sticky gallery, sticky add-to-cart bar, live viewer count)
- `pages/bottle-warmer-bundle-pdp.html` — Bundle version of the same page (generated: edit the warmer page, then run `python3 build.py`)
- `pages/collection.html` — Jewelry-style collection/grid page with hover image swap
- `pages/bracelet-pdp.html` — Bracelet product page

These are static, self-contained HTML files — open any of them directly in a browser to preview.
